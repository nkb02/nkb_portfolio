# Nitish Kumar portfolio

A standalone static portfolio. The deployable site is in `dist/` and requires no build step.

Open `dist/index.html` directly, or serve `dist/` over HTTP:

```sh
python -m http.server 4173 --directory dist
```

Update content in `dist/index.html`, styles in `dist/styles.css`, and the email copy interaction in `dist/portfolio.js`. The portrait is a studio-style edit of the supplied formal photo. Project illustrations are stylized and link to the actual source repositories.
